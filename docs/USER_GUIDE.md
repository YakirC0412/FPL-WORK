# מדריך שימוש

## פתיחת הממשק

הדרך המומלצת במחשב Windows היא להפעיל את `scripts/start-local.bat`. הקובץ יפתח את עמוד הבית בכתובת מקומית בדפדפן.

אפשר להשתמש גם באתר שפורסם דרך GitHub Pages. לא מומלץ לפתוח את קובצי ה־HTML ישירות באמצעות `file://`, מכיוון שהדפדפן עלול לחסום טעינת Excel או יצוא PNG.

## עמוד הבית

הכתובת הראשית פותחת את Homepage של V2. לאחר התחברות באמצעות Google או כניסה כאורח, טוענים קוד ליגה ובוחרים אחת משתי אפשרויות:

1. **Gameweek Data** — נתוני תחילת המחזור.
2. **Gameweek Summary** — סיכום המחזור.

גרסאות V1 הישנות אינן מופיעות בניווט הציבורי ונשמרות בכתובות ישירות לשימוש אדמין בלבד. מאחר שמדובר באתר סטטי, הכתובות הישנות אינן מוגנות בסיסמה.

## עבודה עם דראפטים

הדראפטים נשמרים בדפדפן שבו נוצרו. הם אינם נשמרים אוטומטית בתוך תיקיית הפרויקט ואינם עוברים לטלפון או למחשב אחר.

שינוי בין פתיחה מקומית, GitHub Pages או דומיין אחר יוצר סביבת שמירה נפרדת. לכן מומלץ לא למחוק את נתוני האתר מהדפדפן לפני שסיימת לייצא את הגרפיקה.

## Gameweek Data

1. היכנס באמצעות Google או כאורח והזן את קוד הליגה.
2. לאחר הדדליין, לחץ `Load league`. הודעה מעוצבת תאשר איזה מחזור נטען, או תסביר שנתוני המחזור עדיין אינם זמינים.
3. בחר `Gameweek Data` במסך בחירת הכלים.
4. עבור על הנתונים שהוטענו. תמונות השחקנים מזוהות אוטומטית לפי קוד ושם. בעריכה ידנית, התחל להקליד ובחר את השחקן מהרשימה שמציגה גם את קיצור הקבוצה. הבחירה חשובה במיוחד כאשר יש שני שחקנים בעלי שם זהה.
5. בפאנל `Data Stories` ניתן לבחור שלוש או ארבע תובנות. הפאנל נשאר עצמאי; שימוש בצ'יפים מוצג בשורה מתחת ל־Popular Transfers רק כאשר לפחות צ'יפ אחד גבוה מ־0%.
6. שמור דראפט מקומי, הורד גיבוי JSON לפי הצורך וייצא PNG.

לא נדרש API Key. נתוני ההרכבים זמינים רק אחרי הדדליין של המחזור. ניתן להמשיך להשתמש בתבנית ה־Excel במקרה שרוצים תיקון ידני או אם שירות FPL אינו זמין.

במחשב ניתן לפתוח את אפשרות ה־Excel כנתיב חלופי כאשר טעינת הליגה החיה אינה זמינה או נדרש תיקון ידני.

## Gameweek Recap

1. טען את הליגה בעמוד הבית ובחר `Gameweek Summary` לאחר שהמחזור הסתיים.
2. המערכת בודקת שהמחזור הסתיים ושהתוצאות המדורגות זמינות. אם הנתונים עדיין אינם סופיים תופיע הודעת שגיאה.
3. בדוק את הפודיום, הנתונים הכלליים, ההרכב, הקפטנים והשחקנים המובילים. כל הערכים נשארים ניתנים לעריכה.
   תמונות שחקני ההרכב, הקפטנים והשחקנים המובילים נטענות אוטומטית ממאגר השחקנים המשותף. בשינוי שם ידני יש לבחור את השחקן מההשלמה האוטומטית, שבה מופיע גם קיצור הקבוצה, כדי להבדיל בין שמות כפולים.
4. צור ובחר `Spicy Stats` לפי הנתונים הזמינים.
5. שמור דראפט מקומי, הורד גיבוי JSON לפי הצורך וייצא PNG.

הסנכרון יעבוד רק לאחר ש־FPL סימן את המחזור גם כ־`finished` וגם כ־`data checked`.

## יצוא תמונות

כאשר חיבור ישיר לתיקייה אינו זמין, הקובץ יישמר בתיקיית ההורדות הרגילה של הדפדפן. מומלץ להעביר אותו לאחר מכן לתיקייה המתאימה תחת `exports/`.

## מעבר למחשב או שרת אחר

יש להעביר את כל תיקיית `FPL-WORK`, ולא רק את קובצי ה־HTML. הנכסים, התמונות, תבנית האקסל וקובצי העזר נדרשים להפעלה מלאה.
