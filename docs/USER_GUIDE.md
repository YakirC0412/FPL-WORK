# מדריך שימוש

## פתיחת הממשק

הדרך המומלצת במחשב Windows היא להפעיל את `scripts/start-local.bat`. הקובץ יפתח את עמוד הבית בכתובת מקומית בדפדפן.

אפשר להשתמש גם באתר שפורסם דרך GitHub Pages. לא מומלץ לפתוח את קובצי ה־HTML ישירות באמצעות `file://`, מכיוון שהדפדפן עלול לחסום טעינת Excel או יצוא PNG.

## עמוד הבית

עמוד הבית מציג שלוש אפשרויות:

1. **Gameweek Data** — נתוני תחילת המחזור.
2. **Gameweek Recap** — סיכום המחזור.
3. **Top 3 Differentials** — שלוש המלצות דיפרנציאליות.

כפתור `Home` בכל ממשק מחזיר לעמוד הראשי.

## עבודה עם דראפטים

הדראפטים נשמרים בדפדפן שבו נוצרו. הם אינם נשמרים אוטומטית בתוך תיקיית הפרויקט ואינם עוברים לטלפון או למחשב אחר.

שינוי בין פתיחה מקומית, GitHub Pages או דומיין אחר יוצר סביבת שמירה נפרדת. לכן מומלץ לא למחוק את נתוני האתר מהדפדפן לפני שסיימת לייצא את הגרפיקה.

## Gameweek Data

1. הורד את תבנית ה־Excel מתוך הממשק.
2. מלא את הנתונים בלי לשנות את שמות הגיליונות או הכותרות.
3. העלה את הקובץ דרך `Upload Excel workbook`.
4. עבור על הנתונים שהוטענו והעלה תמונות חסרות.
5. שמור דראפט וייצא PNG.

בחירה ב־`Connect project folder` מאפשרת לדפדפן, לאחר אישור, לשמור את קובץ ה־Excel האחרון תחת `imports/gameweek-data/` ואת התמונות תחת `exports/gameweek-data/`.

## יצוא תמונות

כאשר חיבור ישיר לתיקייה אינו זמין, הקובץ יישמר בתיקיית ההורדות הרגילה של הדפדפן. מומלץ להעביר אותו לאחר מכן לתיקייה המתאימה תחת `exports/`.

## מעבר למחשב או שרת אחר

יש להעביר את כל תיקיית `FPL-WORK`, ולא רק את קובצי ה־HTML. הנכסים, התמונות, תבנית האקסל וקובצי העזר נדרשים להפעלה מלאה.
