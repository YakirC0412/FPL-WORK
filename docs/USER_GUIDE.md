# מדריך שימוש

## פתיחת הממשק

הדרך המומלצת במחשב Windows היא להפעיל את `scripts/start-local.bat`. הקובץ יפתח את עמוד הבית בכתובת מקומית בדפדפן.

אפשר להשתמש גם באתר שפורסם דרך GitHub Pages. לא מומלץ לפתוח את קובצי ה־HTML ישירות באמצעות `file://`, מכיוון שהדפדפן עלול לחסום טעינת Excel או יצוא PNG.

## עמוד הבית

עמוד הבית מציג שלוש אפשרויות:

1. **Gameweek Data** — נתוני תחילת המחזור.
2. **Gameweek Recap** — סיכום המחזור.
3. **Top 3 Differentials** — שלוש המלצות דיפרנציאליות.

כפתור `Home` בכל ממשק מחזיר לעמוד הראשי.

## עבודה עם דראפטים

הדראפטים נשמרים בדפדפן שבו נוצרו. הם אינם נשמרים אוטומטית בתוך תיקיית הפרויקט ואינם עוברים לטלפון או למחשב אחר.

שינוי בין פתיחה מקומית, GitHub Pages או דומיין אחר יוצר סביבת שמירה נפרדת. לכן מומלץ לא למחוק את נתוני האתר מהדפדפן לפני שסיימת לייצא את הגרפיקה.

## Gameweek Data

1. הסנכרון האוטומטי בודק אחת לשעתיים אם נתוני המחזור החדש זמינים. ניתן גם להפעיל את `Sync Gameweek Data` ידנית בלשונית Actions של GitHub.
2. המתן שהפעולה תסתיים ושהאתר יתעדכן.
3. לחץ בממשק על `Load latest FPL data`. הודעה מעוצבת תאשר איזה מחזור נטען, או תסביר שנתוני המחזור עדיין אינם זמינים.
4. עבור על הנתונים שהוטענו והעלה תמונות חסרות.
5. באזור `Chip usage` ניתן ללחוץ `GENERATE AI STATS`, לבחור שלוש או ארבע מתוך עד שמונה תובנות ולהחליף זמנית את פאנל הצ'יפים. `Restore chips` מחזיר את הפאנל המקורי.
6. שמור דראפט וייצא PNG.

לא נדרש API Key. נתוני ההרכבים זמינים רק אחרי הדדליין של המחזור. ניתן להמשיך להשתמש בתבנית ה־Excel במקרה שרוצים תיקון ידני או אם שירות FPL אינו זמין.

בחירה ב־`Connect project folder` מאפשרת לדפדפן, לאחר אישור, לשמור את קובץ ה־Excel האחרון תחת `imports/gameweek-data/` ואת התמונות תחת `exports/gameweek-data/`.

## Gameweek Recap

1. לאחר שהמחזור הסתיים, הפעל ב־GitHub Actions את `Sync Gameweek Recap`.
2. אפשר להשאיר את מספר המחזור ריק כדי לבחור את המחזור האחרון שאושר סופית ב־FPL.
3. לחץ בממשק על `Check & load current recap`. אם נתוני המחזור עדיין אינם סופיים תופיע הודעת שגיאה, ולא ייטען בטעות סיכום ישן.
4. בדוק את הפודיום, הנתונים הכלליים, ההרכב, הקפטנים והשחקנים המובילים. כל הערכים נשארים ניתנים לעריכה.
5. ערוך ידנית את `Spicy Stats`. הסנכרון אינו דורס אותם או את בחירות העיצוב והתמונות הקיימות.
6. שמור את התוצאה כטיוטה חדשה וייצא PNG.

הסנכרון יעבוד רק לאחר ש־FPL סימן את המחזור גם כ־`finished` וגם כ־`data checked`.

## יצוא תמונות

כאשר חיבור ישיר לתיקייה אינו זמין, הקובץ יישמר בתיקיית ההורדות הרגילה של הדפדפן. מומלץ להעביר אותו לאחר מכן לתיקייה המתאימה תחת `exports/`.

## מעבר למחשב או שרת אחר

יש להעביר את כל תיקיית `FPL-WORK`, ולא רק את קובצי ה־HTML. הנכסים, התמונות, תבנית האקסל וקובצי העזר נדרשים להפעלה מלאה.
