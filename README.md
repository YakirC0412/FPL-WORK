# FPL Champions League Studio

A browser-based studio for creating weekly Fantasy Premier League graphics.

- **Gameweek Data** — pre-deadline ownership, captaincy, transfers, chips and effective ownership.
- **Gameweek Recap** — podium, League XI, scorecards and standout stories.
- **Top 3 Differentials** — three ranked low-owned recommendations, editorial reasoning and last-gameweek stats.

Open `index.html` locally or publish the repository with GitHub Pages.
